# Packs

Packs are physical capability boundaries. Profiles compose their contents for
installation into a consumer project.

## Current packs

- `software-engineering`: language, database, OpenAPI, cross-cutting,
  infrastructure, frontend web-quality, browser-testing, form-validation, and
  framework/styling Skills, plus reusable engineering Agents.
- `operations/github`: commit/push, pull request, issue clarification,
  decomposition and implementation, issue creation, an Orca Issue-development
  Automation prompt, Copilot review, security alert, and post-merge Skills.

Future packs such as documentation or research should be added only when they
contain a real capability set and a corresponding Profile.
