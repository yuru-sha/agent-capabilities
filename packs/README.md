# Packs

Packs are physical capability boundaries. Profiles compose their contents for
installation into a consumer project.

## Current packs

- `software-engineering`: language, database, OpenAPI, cross-cutting Skills,
  and reusable engineering Agents.
- `operations/github`: commit/push, pull request, release, issue, Copilot
  review, security alert, and post-merge Skills.

Future packs such as documentation or research should be added only when they
contain a real capability set and a corresponding Profile.
