# Capacity, lifecycle, and operations

Model On-Demand, Spot, Reserved Instances, or Savings Plans against interruption tolerance and utilization.

For Auto Scaling fleets, define health checks, warm-up, replacement policy, minimum healthy capacity, termination protection requirements, and deployment rollback.

Monitor CPU, memory via agent where needed, disk/IO, network, status checks, and application health.

Treat stop/start, reboot, retirement, rebalance, and Spot interruption behavior as tested operational paths.
