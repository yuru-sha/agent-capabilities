# OpenAPI Lint

Use this specialist with the repository's selected OpenAPI version, source of truth, and existing tools. Pair it with the matching language/database specialist when implementation behavior is in scope.

## Rules

- Run the repository's configured linter and record its exact version, config, ignored paths, and warning policy.
- Treat lint as mechanical evidence; a clean result does not prove semantic correctness or enforcement.
- Add or change a rule only when the repository has an owner and a concrete contract reason.
