# OpenAPI Schema governance

Use this specialist with the repository's selected OpenAPI version, source of truth, and existing tools. Pair it with the matching language/database specialist when implementation behavior is in scope.

## Rules

- Use one naming, casing, identifier, date/time, enum, error, and pagination convention across the description.
- Decide required, nullable, additionalProperties, oneOf/anyOf, discriminators, formats, and defaults deliberately.
- Reuse components for stable shared meaning and keep examples valid against constraints without private data.
