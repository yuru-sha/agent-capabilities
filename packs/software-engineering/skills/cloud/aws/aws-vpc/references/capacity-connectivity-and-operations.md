# Capacity, connectivity, and operations

Monitor available subnet IPs, NAT errors/port exhaustion, flow logs where justified, endpoint health, and route changes.

Model ENI usage for ECS awsvpc, EKS CNI, Lambda VPC attachment, load balancers, and interface endpoints.

For hybrid connectivity, define routing propagation, asymmetric-path risks, MTU, DNS forwarding, failover, and ownership.

Document break-glass access and network-change rollback before production routing or security policy changes.
