# Search Ads trafficking

Use Search Ads for text ads triggered by user search queries on Yahoo! JAPAN search results.

## Resolve before entry

- advertising account and billing readiness;
- campaign objective/type and campaign name;
- daily/total budget where supported;
- schedule;
- ad group structure;
- keywords, match behavior, and exclusions;
- bids/bidding strategy;
- targeting settings supported by the current UI;
- ad text/assets and landing URL;
- tracking parameters and conversion measurement;
- initial status.

The current LINEヤフー guide describes the practical setup flow as campaign -> ad group -> keywords -> ad creation, followed by funding/review steps before delivery.

## Safety

- Keep naming stable enough to reconcile UI objects with reports and bulk sheets.
- Validate destination URLs and tracking parameters before enabling.
- Treat keyword/match-type changes as delivery-affecting changes, not cosmetic edits.
- Confirm review state after material ad/URL edits.
- Do not increase bids or budgets merely to resolve lack of delivery unless explicitly requested.
