# TypeScript Documentation

Use this specialist with the global `$tdd` skill for implementation and `$code-review` for review. It owns only TypeScript-specific decisions for this concern.

## Rules

- Keep public types, JSDoc, generated API docs, CLI help, configuration examples, and runtime behavior aligned.
- Document browser/server boundaries, failure modes, compatibility, and security assumptions where users need them.
- Prefer examples that can be type-checked or exercised by existing project commands.
