# Python 3 Documentation

Use the project's TDD workflow for implementation and its review workflow for review. This specialist owns only Python 3-specific decisions for this concern.

## Rules

- Keep public module/class/function docstrings, README instructions, CLI help, configuration examples, and failure behavior aligned.
- State supported Python versions and compatibility boundaries where examples depend on them.
- Prefer examples that can be exercised by the repository's existing checks.
