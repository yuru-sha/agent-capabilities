# Go Code Generation

Use with `openapi-codegen`, `go-struct-json-tags`, or the repository's schema
skill when generated Go code is part of the change.

## Rules

- Locate the generator directive, configuration, pinned tool version, and documented invocation before editing output.
- Keep generated files mechanically reproducible, gofmt-formatted, and clearly separated from hand-written code.
- Change the source schema/template or generator configuration, then regenerate and inspect the complete diff.
- Avoid hand-editing generated output; if an exception is required, document the ownership boundary and regeneration risk.
- Check generated API, JSON tags, imports, error behavior, and compatibility with the repository's build and test commands.
