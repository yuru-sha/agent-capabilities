# OpenAPI Documentation

Use this specialist with the repository's selected OpenAPI version, source of truth, and existing tools. Pair it with the matching language/database specialist when implementation behavior is in scope.

## Rules

- Document purpose, authorization, lifecycle, errors, pagination, idempotency, examples, deprecation, and compatibility.
- Generate human documentation from the authoritative contract when that is the repository convention.
- Label manually maintained material and keep it synchronized with the spec's source of truth.
