# OpenAPI Sample generation

Use this specialist with the repository's selected OpenAPI version, source of truth, and existing tools. Pair it with the matching language/database specialist when implementation behavior is in scope.

## Rules

- Make examples satisfy required fields, constraints, formats, content types, security redaction, and representative error cases.
- Use deterministic synthetic values and cover boundary, pagination, nullability, and validation behavior.
- Validate examples against the schema and never use real credentials or private personal data.
